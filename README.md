# مؤشر المواطن المغربي

لوحة عربية مفتوحة لمتابعة مؤشرات المعيشة والعمل والسكن والتنافسية في المغرب مع إظهار الفترة والمصدر والمنهجية.

> **الحالة:** نسخة أولية. لا تتضمن هذه النسخة قيماً إحصائية منشورة؛ تظهر المؤشرات كغير متاحة إلى أن تُراجع سلسلة البيانات ومصدرها. لا تمثل الجهات المرتبطة بالمصادر المذكورة.

## تشغيل محلي

يتطلب Python 3.11 أو أحدث، ولا يحتاج إلى مكتبات خارجية:

```bash
python src/generator.py
```

ينتج الموقع الثابت في `output/index.html`. افتح الملف في المتصفح أو استخدم خادماً محلياً:

```bash
python -m http.server 8000 --directory output
```

## إضافة البيانات

حرر `data/indicators.json`. لكل مؤشر يمكن ضبط `value`, `unit`, `period`, `reference` و`source_url`. لا تملأ القيمة إلا بعد التحقق من المصدر وتعريف المؤشر والفترة المرجعية. احرص على أن يتضمن `reference` اسم التقرير أو الجدول ورقم الصفحة/الرابط الدقيق.

الموقع يعرض إشعار النسخة الأولية بصورة ثابتة إلى حين مراجعة وإقرار نشر البيانات؛ لا تعتبر مجرد إضافة قيمة إلى JSON اعتماداً تحريرياً لها.
